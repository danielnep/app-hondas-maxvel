# Estado de qualidade · Hondas Maxvel
**11/10/2026 · Horizon**

## Implementação confirmada
- Aplicação web mobile-first, mapa real quando online, simulação transparente, ronda e supervisão interativas.
- APK Android de **teste** compilado com JDK 17, Android SDK 35 e Gradle 8.9, incluindo o mesmo frontend do site. [Compilação mais recente](https://github.com/danielnep/app-hondas-maxvel/actions/runs/38181271685).
- Testes automatizados Node concluídos. [Histórico das execuções](https://github.com/danielnep/app-hondas-maxvel/actions).
- Auditoria Chromium de **112 estados** em 8 larguras, entre 320 e 1920 px, sem erros de fluxo nem rolagem horizontal global. [Relatório de referência](https://github.com/danielnep/app-hondas-maxvel/actions/runs/38180576008).
- Auditoria de acessibilidade **axe-core, 12 estados**, em 390 e 1440 px: após correções de rótulos, contraste e toque, **zero ocorrências automáticas**. [Execução](https://github.com/danielnep/app-hondas-maxvel/actions/runs/38181271636). Isso não representa aprovação completa WCAG ou TalkBack.

## Corrigido durante o build Android
1. Configuração de SDK no executor atualizada para o SDK preinstalado.
2. Ícone movido para a pasta Android `res/drawable`, tornando-o disponível ao compilador.
3. Build debug executado e APK validado como pacote Android.

## Impedimentos de produção
- A API de supervisão remota, autenticação e entrega de notificações ainda não foi implantada.
- Localização em segundo plano requer teste de aparelhos reais e conformidade com permissões Android. Não funciona após parada forçada pelo usuário.
- Segurança, autorização por perfil, armazenamento e retenção de dados pessoais necessitam implementação e revisão para produção.
- A ponte Android/WebView e carregamento de scripts externos requerem fortalecimento antes de usar com dados reais de colaboradores.
- Testes com TalkBack, acessibilidade humana e piloto de campo ainda pendentes.

**Decisão:** apresentar o site como plataforma interativa e o APK como compilação de teste, sem afirmar homologação operacional.

Acompanhar pendências na [Etapa 07](https://github.com/danielnep/app-hondas-maxvel/issues/7).
